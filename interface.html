一、初始化

AiFlow.init(container, options)

在指定容器上初始化流程设计器，返回设计器实例对象。

var designer = AiFlow.init(document.getElementById('aiflow-page'), {
  title: '我的流程',
  readonly: false,
  events: {
    onNodeCreated: function(data) { console.log(data); },
    onNodeDeleted: function(data) { console.log(data); },
    onLinkCreated: function(data) { console.log(data); },
    onLinkDeleted: function(data) { console.log(data); },
    onContextMenuClick: function(data) { console.log(data); }
  }
});

→ 查看 Demo

参数类型说明
titleString设计器标题，默认"流程设计器"
readonlyBoolean是否只读模式，默认 false
headerObject头部配置 {visible}，visible 为 false 时初始隐藏头部整行
toolbarObject左侧工具栏配置 {visible}，visible 为 false 时初始隐藏工具栏
canvasObject画布配置 {width, height, minWidth, minHeight}
zoomObject缩放配置 {min, max, step, default}
nodeTypesObject覆盖节点类型默认样式
anchorObject覆盖锚点默认样式
linkObject覆盖连线默认样式
contextMenuObject覆盖默认右键菜单
eventsObject事件回调函数，见"五、事件"

二、设计器接口

方法 designer.exportJSON()

导出画布内容为 JSON 对象。

var json = designer.exportJSON();
console.log(JSON.stringify(json, null, 2));

→ 查看 Demo

方法 designer.importJSON(json)

导入 JSON 数据，恢复画布内容。会清除当前画布上所有元素。

designer.importJSON({
  nodes: [...],
  links: [...]
});

→ 查看 Demo

方法 designer.setReadonly(boolean)

设置设计器为只读模式。只读状态下：右键菜单隐藏删除项、不能复制节点、不能拖动连线、不能按Delete键删除。

designer.setReadonly(true);  // 只读
designer.setReadonly(false); // 可编辑

→ 查看 Demo

方法 designer.setEditable()

设置设计器为可编辑模式，等同于 setReadonly(false)。

方法 designer.setTitle(text)

设置设计器标题。

designer.setTitle('审批流程设计');

→ 查看 Demo

方法 designer.showHeader() / designer.hideHeader() / designer.isHeaderVisible()

显示 / 隐藏设计器头部（标题 + 撤销、重做、导入、导出按钮整行）。隐藏后画布主区域自动撑满；头部隐藏期间撤销/重做等快捷键（Ctrl+Z / Ctrl+Y）仍然生效。isHeaderVisible() 返回当前头部是否可见。

designer.hideHeader();       // 隐藏头部
designer.showHeader();       // 显示头部
designer.isHeaderVisible();  // → true / false

也可在初始化配置中直接隐藏：AiFlow.init(el, { header: { visible: false } })

→ 查看 Demo

方法 designer.showToolbar() / designer.hideToolbar() / designer.isToolbarVisible()

显示 / 隐藏左侧工具栏（节点面板）。隐藏后画布区域自动撑满，已有节点与连线不受影响；重新显示后可继续从工具栏拖拽创建节点。isToolbarVisible() 返回当前工具栏是否可见。

designer.hideToolbar();       // 隐藏工具栏
designer.showToolbar();       // 显示工具栏
designer.isToolbarVisible();  // → true / false

也可在初始化配置中直接隐藏：AiFlow.init(el, { toolbar: { visible: false } })

→ 查看 Demo

designer.setLinkContextMenu([
  { name: '设置条件', action: 'condition', callback: function(link) { /* ... */ } },
  { name: '删除', action: 'delete' }

→ 连线右键菜单 Demo  |  → 综合右键菜单 Demo

方法 designer.exportPNG(callback)

导出画布为 PNG 图片。如传入 callback 则回调返回 dataURL，否则自动下载。

designer.exportPNG(function(dataURL) {
  var img = new Image();
  img.src = dataURL;
  document.body.appendChild(img);
});

→ 查看 Demo

方法 designer.addNode(type, x, y, extra)

通过接口创建节点。type 为 start / end / userTask / systemTask / gateway。返回节点对象。

var node = designer.addNode('userTask', 200, 150, { name: '审批' });

三、节点接口

属性 node.id / node.type / node.name / node.x / node.y

节点的基本属性，均可读取。

方法 node.setName(name)

修改节点名称。

node.setName('财务审核');

→ 查看 Demo

方法 node.setStyle(style)

修改单个节点样式，优先级高于设计器统一配置。

node.setStyle({
  fill: '#ffe58f',
  stroke: '#faad14',
  textStyle: { fill: '#000', 'font-size': '14px' }
});

→ 查看 Demo

方法 node.setReadonly(boolean)

设置单个节点为只读/可编辑。

node.setReadonly(true);

方法 node.setContextMenu(items)

自定义单个节点的右键菜单，优先级高于设计器统一配置。

node.setContextMenu([
  { name: '查看详情', action: 'detail', callback: function(n) { alert(n.name); } },
  { name: '删除', action: 'delete' }
]);

方法 node.delete()

删除节点及其所有关联连线。

node.delete();

四、连线接口

属性 link.id / link.startNodeId / link.endNodeId / link.remark

连线的基本属性，均可读取。

方法 link.setRemark(text)

修改连线的备注文本。

link.setRemark('金额>100元');

→ 查看 Demo

方法 link.setStyle(style)

修改单条连线样式，优先级高于设计器统一配置。

link.setStyle({
  stroke: '#f5222d',
  strokeWidth: 3
});

→ 查看 Demo

方法 link.setReadonly(boolean)

设置单条连线为只读/可编辑。

方法 link.setContextMenu(items)

自定义单条连线的右键菜单。

方法 link.resetPath()

重置连线路径（重新自动计算路由）。

方法 link.delete()

删除连线。

五、事件

事件名触发时机回调参数
事件 onNodeCreated节点创建完成{id, name, type}
事件 onNodeDeleted节点删除完成{id, name, type}
事件 onLinkCreated连线创建完成{id, startNodeId, endNodeId}
事件 onLinkDeleted连线删除完成{id, startNodeId, endNodeId}
事件 onContextMenuClick右键菜单点击{targetType, targetId, menuName}

六、数据格式

exportJSON / importJSON 使用的 JSON 格式：

{
  "nodes": [
    {
      "id": "guid",
      "type": "start | end | userTask | systemTask | gateway",
      "name": "节点名称",
      "x": 100,
      "y": 200,
      "style": null
    }
  ],
  "links": [
    {
      "id": "guid",
      "startNodeId": "guid",
      "startAnchorPos": "top | bottom | left | right",
      "endNodeId": "guid",
      "endAnchorPos": "top | bottom | left | right",
      "remark": "条件说明",
      "style": null
    }
  ]
}
