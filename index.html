Features

为流程编排而生的核心能力

从节点创建、连线路由到数据导入导出，提供一套完整且轻量的可视化设计体验。

+

节点拖拽编排

从工具栏拖拽创建开始、结束、用户任务、系统任务和判断节点。

⌁

正交智能连线

通过锚点快速创建连线，自动计算正交路径，并支持线段手动调整。

⌖

对齐与框选

拖动节点时显示对齐参考线，支持框选和批量移动多个节点。

↺

撤销与重做

编辑过程自动记录历史状态，支持快捷键和顶部按钮快速回退。

{ }

JSON 导入导出

流程数据可序列化保存，并还原节点、连线、样式和手动折点。

▣

PNG 图片导出

一键将当前流程画布导出为 PNG 图片，便于分享和归档。

Workflow

从拖拽到数据交付，只需三步

保持简单清晰的开发模型，让业务团队快速完成流程搭建，让研发团队专注于业务接入。

✓拖拽节点并连接锚点，完成流程结构设计
✓调整节点样式、连线规则、备注和只读状态
✓导出 JSON 接入后端，或导出 PNG 用于展示归档
app.js
// 初始化设计器
import { AiFlow } from './Content/es6/index.js';

const designer = AiFlow.init(
  document.getElementById('aiflow-page'),
  {
    title: '审批流程',
    events: {
      onNodeCreated(data) { console.log(data); },
      onLinkCreated(data) { console.log(data); }
    }
  }
);

// 导出流程数据
const json = designer.exportJSON();
How it works

一套简单而完整的工作方式

01

设计流程

从左侧工具栏拖入节点，移动节点并利用对齐参考线完成画布布局。

02

配置关系

在节点锚点之间创建连线，设置规则备注、样式和自定义右键菜单。

03

接入业务

监听节点与连线事件，通过 JSON 数据将流程保存到后端服务。
